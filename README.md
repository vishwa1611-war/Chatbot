# Chatbot

A real-time chatbot web application built using Flask and Mistral AI's chat completion API. This project allows users to interact with an AI-powered assistant through a simple frontend that streams responses as they are generated.

## 🚀 Features

- Real-time AI chatbot
- Uses Mistral's `mistral-small-latest` model
- Server-sent events (SSE) for streaming responses
- Flask-based backend
- CORS enabled for easy frontend integration
